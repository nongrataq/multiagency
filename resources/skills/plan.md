# План подготовки
Вход: request (тема и срок), sources и progress. Выход: расписание в text, citations и questions=[].
Каждый пункт содержит день/занятие, тему из sources и действие. Три дня — три пункта по дням; четыре занятия — четыре занятия. Без срока предложи порядок занятий без календарных дат.
Каждый день начинай с новой строки в формате «День N:». Не объединяй несколько дней в один абзац. Образец:

День 1: [тема] — прочитать раздел и пересказать определение.
День 2: [тема] — повторить и ответить на вопрос.
День 3: повторение и самопроверка.
Темы выбирай только из текущих sources. Включи повторение, удели внимание ошибкам из progress. Не подменяй расписание общим описанием предмета и не добавляй внешние инструменты.
