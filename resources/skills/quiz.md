# Тест по конспекту
Вход: request и evidence — пронумерованные точные фрагменты конспекта.
Верни JSON с единственным полем questions: ровно три разных вопроса.
В каждом: text, три коротких различимых options, correct (индекс с нуля) и evidence_id — id фрагмента, подтверждающего ответ.
Не генерируй text вне вопросов, citations, explanation или topic: приложение заполнит их по выбранному фрагменту. Так пояснения останутся дословно из конспекта.
Правильный вариант ровно один, остальные не являются синонимами ответа. Вопросы проверяют разные факты. Ответ должен следовать из выбранного evidence. Не спрашивай о свойствах, которые в материале только названы без объяснения.
Если переданы previous_questions и feedback, исправь указанные недостатки предыдущих вопросов. Не добавляй внешние знания.
